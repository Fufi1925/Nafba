# Sicherheit

Keine Zugangsdaten oder Signierschlüssel in öffentliche Issues posten. Sicherheitsprobleme über GitHubs private Vulnerability Reporting melden, sofern im Repo aktiviert. Falls nicht aktiviert, zunächst ein Issue ohne technische Details erstellen und um einen privaten Kontakt bitten.

Release-APKs anhand der veröffentlichten SHA-256-Prüfsummen vergleichen. Der Release-Schlüssel muss für App-Updates dauerhaft erhalten bleiben und darf nicht in Git gespeichert werden.
